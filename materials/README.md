## 使用与更新

PDF 可以直接打开；Python 讲义可以先作为源码阅读，运行环境的原始说明见[官方 README](lectures/README.md)。

个人笔记放在项目的 [notes/](../notes/)，实验放在 [experiments/](../experiments/)。保留 `lectures/` 中的官方原文，便于与上游版本比较。

后续更新时，先查看上游新增提交，再将选定提交的文件快照同步到 `lectures/`，同时更新这里记录的提交 SHA、日期和讲义索引。
